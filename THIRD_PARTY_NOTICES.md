## Microsoft and .NET packages

The WinUI controller restores Microsoft Windows App SDK, Windows SDK Build Tools, and their transitive dependencies from NuGet. These packages are not vendored in the source repository.

Binary release archives may contain redistributable assemblies from Windows App SDK, WebView2, Windows App SDK ML, and .NET packages. Their original license and notice files are included in the release archive under `licenses/` when those assemblies are packaged.
